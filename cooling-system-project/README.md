# Cooling System Design (Project N1)

## 📌 Description

Design of a closed-loop cooling system for industrial equipment.

## ⚙️ Parameters

* Flow rate: 10 m³/h
* Temperature: 12 → 18°C
* Medium: water

## 🧩 System includes

* Pump
* Heat exchanger
* Consumer
* Filter
* Control valves

## 🎯 Objectives

* Ensure stable cooling
* Allow maintenance without shutdown
* Provide monitoring and emergency protection
